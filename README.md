## 📱 مميزات التطبيق

- **تصميم متجاوب ومتوافق مع شاشات الهواتف الذكية (Mobile-First)**: تجربة مستخدم سريعة وسلسة ومريحة للاستخدام الميداني داخل الصيدلية.
- **تصفح هرمي أكاديمي (Accordion Tree)**: تدرج شجري يبدأ من الفصل (Chapter) ← القسم (Section) ← العائلة الدوائية (Drug Family) ← الاسم العلمي (Generic Name) ← الأسماء التجارية في الأردن (Trade Names).
- **بحث فوري ذكي (Live Search)**: إمكانية البحث الفوري بالاسم التجاري أو العلمي مع إبراز المسار الهرمي لكل نتيجة.
- **بطاقة الدواء الشاملة (Drug Modal)**:
  - صورة العبوة الحقيقية المتوفرة بالسوق الأردني.
  - الاسم التجاري والعلمي والشركة الصانعة / المستودع الموزع.
  - جدول الأشكال الصيدلانية والعيارات والجرعات الموحدة.
  - قائمة البدائل الدوائية المتاحة لنفس المادة الفعالة مع إمكانية الانتقال المباشر إليها.
- **فلترة الفصول**: أزرار سريعة لعرض كل فصل على حدة أو استعراض الدليل كاملاً.

## 📊 محتويات الدليل وقاعدة البيانات (الفصول 1 إلى 5)

| الفصل | المحتوى العلمي |
|---|---|
| **الفصل 1 (Chapter 1)** | أدوية الجهاز الهضمي (GI System): أدوية الحموضة والارتجاع، مضادات التشنج، أدوية الإسهال والإمساك، مضادات القيء والغثيان، والمطهرات المعوية. |
| **الفصل 2 (Chapter 2)** | المسكنات ومضادات الالتهاب وبواسط العضلات (Analgesics & NSAIDs): الباراسيتامول، المسكنات غير الستيرويدية، باسطات العضلات، أدوية الشقيقة، وأدوية النقرس. |
| **الفصل 3 (Chapter 3)** | أدوية الجهاز التنفسي والتحسس والربو (Respiratory System): أدوية السعال بأنواعه، مضادات الهيستامين، بخاخات الربو وموسعات القصبات، ومثبطات اللوكوترين. |
| **الفصل 4 (Chapter 4)** | المضادات الحيوية ومضادات الفطريات والفيروسات (Anti-Infectives): البنسلينات ومشاركات الكلافولانيك، السيفالوسبورينات، الماكروليدات، الكينولونات، التتراسيكلينات، مضادات الفطريات الجلدية والشامبوهات، والأسيكلوفير. |
| **الفصل 5 (Chapter 5)** | أدوية ومستحضرات العيون والأنف والأذن (Eye, Nasal & Ear Drops): مضادات عدوى العين، مضادات التحسس والالتهاب، قطرات وبدائل الدموع، أدوية الجلوكوما، بخاخات الأنف والسالاين ومضادات الاحتقان، وقطرات ومذيبات شمع الأذن. |

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3**: تصميم واجهة مخصص يدعم اللغة العربية واتجاه القراءة (RTL) بشكل أصيل، مع استعراض الأسماء الطبية بالإنجليزية (LTR).
- **Vanilla JavaScript**: أداء فائق وسرعة تحميل فورية بدون أي مكتبات أو أطر عمل ثقيلة.
- **Embedded Base64 Media**: صور العبوات مدمجة ومضغوطة لتعمل مباشرة بدون تأخير في التحميل ودون الحاجة لاتصال سيرفر خارجي.
- **GitHub Pages**: استضافة سحابية ثابتة وفائقة السرعة.
